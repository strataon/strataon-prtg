# STRATAON PRTG Integration

Official PRTG integration resources for STRATAON devices.

This repository provides official PRTG OID Library files for monitoring STRATAON products through SNMP using PRTG Network Monitor.

## Supported Products

The current STRATAON PRTG integration includes support for:

- miniPLC
- smartPDU
- miniENV
- sentiaMAN
- sentiaPRO
- sentiaLOK

Support may vary according to product model and firmware version.

## Requirements

- PRTG Network Monitor
- SNMP enabled on the STRATAON device
- Network connectivity between the PRTG probe and the monitored device
